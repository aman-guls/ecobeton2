# ЭкоБетон v2 — реальные данные о почве + экобетон с золой и стеклом

Кликаете по карте → сервер запрашивает **реальные** данные о почве и климате →
по ним считается состав бетона на 1 м³ (цемент + **зола-унос** + **стеклянная пыль**).

⚠️ Результаты предварительные. Несущая способность — оценка по типу/плотности/влажности,
сульфаты — косвенная оценка (или ваш лабораторный результат). Это не замена
инженерно-геологическим изысканиям и лабораторному подбору состава.

## Структура

```
ecobeton_mvp/
├── app.py             # Flask: маршруты, валидация
├── soil_service.py    # запросы к SoilGrids и Open-Meteo, кэш, повторы
├── geotech.py         # тип грунта, несущая способность, риск сульфатов
├── concrete.py        # расчёт состава (цемент/зола/стекло/заполнители/добавки)
├── requirements.txt
├── templates/index.html
└── static/{style.css, script.js}
```

## Запуск

```bash
python -m venv venv && source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py                                      # http://127.0.0.1:5000
```
Нужен интернет (сервер ходит во внешние API). Ключи не нужны.
Продакшен: `gunicorn -w 2 -t 90 app:app`.

## Откуда данные

| Что | Источник | Примечание |
|---|---|---|
| глина/песок/пыль, pH, плотность, органика, камни | SoilGrids v2 (ISRIC) | сетка 250 м, среднее по 0–100 см, модельные данные |
| влажность почвы | Open-Meteo Forecast | слой 9–27 см, среднее за 30 суток |
| осадки, испарение, морозные циклы, t мин | Open-Meteo Archive | последние 365 суток |
| сульфаты | лаборатория (поле ввода) или оценка | в открытых API глобально их нет |

SoilGrids иногда медленный и ограничивает частоту (~5 запросов/мин) — поэтому есть
кэш на 6 часов, повторные попытки и понятные сообщения об ошибках. Если недоступны
только Open-Meteo, сайт продолжит работать с предупреждением.

## Как считается бетон

1. Класс по несущей способности: <1 → B30, <2 → B25, 2–4 → B22.5, >4 → B20.
2. Ограничение В/В по влажности, сульфатам, морозным циклам (0.45–0.60), классы W и F.
3. Зола-унос 15–30 %, стеклянная пыль 10–15 % от массы вяжущего (больше золы при
   сульфатах, меньше при слабом грунте и морозах).
4. Прочность по Боломею–Скрамтаеву с коэффициентами эффективности золы (0.45) и стекла (0.60).
5. Песок и щебень — по абсолютным объёмам (сумма = 1000 л).
6. Экономия цемента и CO₂ (0.85 кг CO₂/кг цемента) относительно бетона без добавок.

Все константы — в начале `concrete.py` и `geotech.py`.

## Что можно улучшить дальше

- Загрузить свои данные скважин/изысканий (БД) и брать их вместо SoilGrids, где они есть.
- Уровень грунтовых вод и химия воды (в бесплатных глобальных API нет).
- Калибровка коэффициентов по лабораторным испытаниям (зола Экибастуза, местное стекло).
- Экспорт результата в PDF, история расчётов.
